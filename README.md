# З. Батбаярын сайт

Монгол/англи хоёр хэлтэй сайт, блог, нийтлэл оруулах админ хэсэгтэй.

## Хавтасны бүтэц

| Файл / хавтас | Юу вэ |
|---|---|
| `index.html` | Сайтын нүүр хуудас (бүх хэсэг нэг файлд) |
| `admin/` | Нийтлэл бичих админ хэсэг (`/admin/` хаягаар нээгдэнэ) |
| `admin/config.yml` | Админы тохиргоо: талбарууд, ангиллууд |
| `posts/` | Нийтлэлүүд. Админаас нийтлэхэд энд автоматаар нэмэгдэнэ |
| `uploads/` | Админаас оруулсан зургууд |
| `scripts/build.mjs` | Нийтлэлүүдийг `posts.json` болгох скрипт (Netlify ажиллуулна) |
| `netlify.toml` | Netlify-н тохиргоо |

## Нийтлэл нэмэх

1. `https://ТАНЫ-САЙТ/admin/` руу орж нэвтэрнэ.
2. **New нийтлэл** дарж монгол (заавал), англи (сонголттой) хувилбарыг бичнэ.
3. **Publish → Publish now** дарна. 1–2 минутын дараа сайтад гарна.

## Анхаарах

- Ангилал нэмэх, өөрчлөх бол `admin/config.yml` болон `index.html` доторх `CATS` хоёуланг нь засна.
- `posts/` доторх "Жишээ нийтлэл"-үүдийг админаас устгаарай.
- Холбоо барих мэдээлэл, зургийн орлуулгууд `index.html` дотор байна.
